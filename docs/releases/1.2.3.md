# 1.2.3 版本变更

上一版：1.2.2。

## 本次修改

- 地区副标题独占一行，长省名和自治州自然换行，修复定位库尔勒时标题、按钮重叠及城市名被挤压。
- 切换城市取消旧请求并丢弃过期结果，主页回到顶部，清空上一城市提示，避免手动新增城市后停在中部或出现空白卡片。
- 按下即响应、松手回弹，进入与返回统一过渡；去除实时背景模糊、持续云层位移及整张长页面动画。
- 桌面卡片独立保存定位城市与天气，不再被应用手动选城覆盖；后台定位随位置变化刷新，并明确权限及失败回退。
