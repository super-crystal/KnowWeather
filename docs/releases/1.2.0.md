# 1.2.0 版本变更

上一版：1.1.0。

## 本次修改

- 未来 7 日扩展到 15 日：按日期合并地区模型与 Best Match 补充预报，逐日注明来源，不虚构缺失数值。
- 主页按天气及昼夜切换背景，城市选择移到右上角；新增城市管理，支持搜索、添加、切换、排序及移除。
- 新增天气详情：实况、48 小时、15 日、空气质量、气象信息、日出日落、生活建议、天气地图、台风、双城比较、预警。
- 接入 RainViewer 雷达历史帧、中央气象台台风公开资料和分地区预警；双城比较支持温度趋势。
- Leaflet 随包内置，修复 Windows 打包资源路径，不添加广告或内容推荐。

## 实际界面文件差异

本节比较两个原始 APK 内的文件校验值，不靠文件修改时间判断。

- 新增：`cities.mjs`, `weather-data.mjs`, `vendor/LICENSE-Leaflet.txt`, `vendor/images/layers-2x.png`, `vendor/images/layers.png`, `vendor/images/marker-icon-2x.png`, `vendor/images/marker-icon.png`, `vendor/images/marker-shadow.png`, `vendor/leaflet.css`, `vendor/leaflet.js`。
- 修改：`app.js`, `index.html`, `native.js`, `style.css`。
- 移除：无。
- 原生 dex：有变化。

机器可读的完整差异见 [asset-diff.json](provenance/asset-diff.json)。

## 本版尚未完成的后续改动

- 底图依赖在线 OpenStreetMap，手机网络失败时可能只显示回波／路径而没有地理参照；后续在 1.2.1 修复。
- 当前天气是模型估算，雷达与预警覆盖有地区限制。
