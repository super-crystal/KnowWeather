# 1.0.0 版本变更

上一版：原始网页版（未编号）。

## 本次修改

- 将原网页版天气页面封装为 Android 应用，内置 HTML、CSS、JavaScript 和受限原生桥接文件。
- 保留城市搜索与选择、按地区自动匹配天气模型、未来 7 日预报、逐小时信息及明暗主题。
- 包名 cn.weatherly.app，versionCode 1；最低 API 23，目标与编译 API 35。

## 实际界面文件差异

本节比较两个原始 APK 内的文件校验值，不靠文件修改时间判断。

- 新增：`app.js`, `index.html`, `native.js`, `style.css`。
- 修改：无。
- 移除：无。
- 原生 dex：首版基线。

机器可读的完整差异见 [asset-diff.json](provenance/asset-diff.json)。首版文件列表作为安卓归档基线，不意味着这些文件在网页版中全是新增。

## 本版尚未完成的后续改动

- 本版没有后续增加的中国气象局 CMA 手动选项和 Android 桌面卡片。
- 没有找到独立的本版历史验证报告，不补写为已完成实机测试。

整理时保留发布包原字节，没有把新版源码换上旧版本号，也没有修改历史验证报告的正文。
