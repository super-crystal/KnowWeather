# 1.1.0 版本变更

上一版：1.0.0。

## 本次修改

- 中国地区新增中国气象局 CMA 可选源（通过 Open-Meteo 获取），不可用时回退并显示实际来源；海外仍自动匹配模型。
- 新增卡片中心，提供实时天气、日出日落两种标准 Android 桌面小组件及四种外观。
- 卡片城市、温度单位与应用同步；支持缓存与原生后台更新。
- 目标与编译 SDK 升至 Android 16 / API 36，versionCode 2，预报仍为 7 日。

## 实际界面文件差异

本节比较两个原始 APK 内的文件校验值，不靠文件修改时间判断。

- 新增：无。
- 修改：`app.js`, `index.html`, `native.js`, `style.css`。
- 移除：无。
- 原生 dex：有变化。

机器可读的完整差异见 [asset-diff.json](provenance/asset-diff.json)。

## 本版尚未完成的后续改动

- 此时卡片跟随应用城市；独立定位卡片直到 1.2.3 才实现。
- 厂商专有卡片中心的收录取决于桌面系统；CMA 不是直接连接中国气象局站点。
