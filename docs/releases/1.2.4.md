# 1.2.4 版本变更

上一版：1.2.3。

## 本次修改

- 修复第二云层缩放后边缘落在屏内导致的主页右侧硬接缝，改为超出视口的完整渐变覆盖。
- 城市管理、天气详情和主页功能卡片从实际点击按钮的边界展开至全屏（420 ms），返回时缩回来源按钮（300 ms）。
- 详情分类下划线平滑移动、分类栏自动居中滚动，内容按点击方向左右过渡（340 ms）。
- 快速连续点击取消上一次过渡，以最后选择为准；相同分类不重复加载。
- 仅对可见视口执行长列表过渡，动画结束／取消后恢复尺寸与布局；遵循减少动态效果设置，并支持分类键盘导航。

## 实际界面文件差异

本节比较两个原始 APK 内的文件校验值，不靠文件修改时间判断。

- 新增：无。
- 修改：`app.js`, `interactions.mjs`, `style.css`。
- 移除：无。
- 原生 dex：有变化。

机器可读的完整差异见 [asset-diff.json](provenance/asset-diff.json)。

## 本版尚未完成的后续改动

- 模拟器验证了动画方向与收尾，不代表真实手机达到参考视频的 FPS。
- 沿用既有天气、雷达、预警覆盖与后台定位限制。

整理时保留发布包原字节，没有把新版源码换上旧版本号，也没有修改历史验证报告的正文。
