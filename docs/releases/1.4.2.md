# 知天气 1.4.2

空气质量可在首页底部和详情底部切换 CAMS / Open-Meteo、WAQI / AQICN、OpenWeather 与香港环保署，选择自动保存。WAQI和OpenWeather提供个人密钥配置、替换和清除入口；未配置时明确提示。

不同来源分别显示美国AQI、OpenWeather 1–5级或香港AQHI，保留数据时间与原机构署名；WAQI污染物为分指数并显示站点距离，其他支持浓度的来源显示μg/m³。香港仅提供该地区资料，主值为有效一般监测站最高值，各站单独列出。

加入资料时效、缓存隔离及请求乱序保护；WAQI资料不落盘。修复天气刷新结束时重绘空气质量详情而打断选择，以及浅色面板来源按钮文字不清晰。

验证：39项自动检查通过，Edge移动视口交互通过，CAMS与香港官方接口实测通过；WAQI/OpenWeather仅完成模拟响应测试，需在应用内配置个人密钥后使用。正式APK使用既有签名，版本代码12。未进行安卓实体设备运行测试。来源及授权说明见[空气质量数据源](../空气质量数据源.md)。
