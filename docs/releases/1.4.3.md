# 知天气 1.4.3

修复雨天背景在上下滑动时暂停的问题：移除滚动事件的主动暂停及延迟恢复逻辑，滑动时天空动画继续播放；切到后台、打开弹窗或开启减少动态效果时保留暂停行为。

根据当前降水量改变雨滴长度、粗细、数量和落速，小雨细而稀，大雨更长、更粗、更密。降水量缺失时参考天气代码，极端值限幅；雨粒子最多110个。视觉表现是天气资料的示意，不是实际雨滴尺寸测量。
