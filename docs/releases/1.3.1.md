# 1.3.1 相对 1.3.0 的修改

原来中国地区数据源、天气/台风底图、对比城市打开Android原生select菜单，样式与应用不同。本版在choices.mjs统一接管选择器，打开带圆角、说明和选中标记的底部面板；原select隐藏后继续承载原值与change事件，保留原天气/地图数据逻辑。动态内容刷新自动接管；地图销毁时关闭过期选择面板。按钮沿用按压弹簧，面板从底部滑入和滑出，支持返回、关闭、点击背景及键盘导航。

index.html去掉主题选择，保留温度单位；style.css移除深色变量与天空加暗层。app.js/native.js固定浅色且迁移旧缓存。motion.mjs删除主题快照过渡。MainActivity的系统栏与卡片中心固定浅色；主页仍匹配真实天气天空颜色。CardCenterActivity用分段按钮替换单选圆圈，移除强制深色/系统选项；CardRenderer仅随实际昼夜或指定浅色绘制。

AndroidManifest、应用标识与build更新1.3.1/code9。start-qa-emulator.ps1加入本地模拟器支持的-crash-report-mode disabled与-no-metrics，绕过报告程序弹窗，不改Windows全局设置。旧版本目录与APK不修改。
