# 1.4.0 相对 1.3.1 的修改

原来背景为静态天空及少量CSS效果。本版新增sky.mjs/sky-model.mjs，app.js把实际天气场景与昼夜传入引擎，style.css切换Canvas与静态回退。Canvas只创建一次，缓存离屏云纹理/光晕，云层按不同速度漂移，雨雪粒子按远近变化；不改天气数据来源及地图逻辑。

根据用户“多云背景充满云”的要求，云带纵向覆盖全屏，水平纹理交叠循环，并增加云团轮廓、深浅和遮光层，避免文字被亮云淹没。晴天与密云场景分别控制云量。夜晚使用独立深色云与星月；雷暴采用缓慢微弱闪光。

限制总像素60万、粒子110以内；持续绘制开销偏高时降低分辨率与目标帧率。弹窗、滚动、后台和减少动态效果暂停；补充逐帧检查与低频恢复探测，兼容WebView媒体变化事件延迟。正式WebView调试关闭；QA副本单独开启检查，未作为发布包。

Manifest/build/MainActivity同步1.4.0/code10。参考APK的ABI、shader/视频通道和许可分析见project/docs/ColorOS动态天气分析.md；参考包无法在现有x86_64模拟器安装，ARM转译镜像验证后置，没有打包参考厂商资产。
