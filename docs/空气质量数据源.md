# 空气质量数据源

核实日期：2026-10-28。首页底部「空气质量数据源」和空气质量详情底部均可切换，选择自动保存；请求失败明确提示，不暗中换源。

| 来源 | 覆盖及类型 | 指数与污染物 | 凭据 |
| --- | --- | --- | --- |
| CAMS / Open-Meteo | 全球模型估算；中国约45公里网格 | 美国 AQI；浓度 μg/m³ | 不需要 |
| WAQI / AQICN | 坐标附近监测站，覆盖取决于站点 | 美国 AQI；污染物为分指数，不能当作浓度 | 个人 Token |
| OpenWeather | 全球空气污染资料 | 独立1–5级；浓度 μg/m³ | 个人 API Key |
| 香港环保署 / DATA.GOV.HK | 香港官方监测站 | AQHI 1–10和10+；主值为有效一般监测站最高值，各站另列 | 不需要；仅香港城市 |

入口沿用现有圆角底部选项面板。需密钥的来源在详情底部提供配置按钮，首页底部也可打开配置；输入框遮掩，关闭后清空输入。凭据只存在本机应用存储，查询时通过 HTTPS 发送给对应服务，不写进源码、安装包、日志或发布附件。没有内置共享密钥，不调用演示 Token 冒充真实城市。

结果显示数据时间、获取时间、原机构署名和站点距所选坐标的距离（WAQI）。数据时间超过6小时或超前1小时则拒绝作为当前资料。非WAQI来源可在请求失败时显示6小时内缓存，按城市及来源隔离并标明缓存；WAQI资料不落盘、不提供离线缓存。不同来源不混用标准，也不由即时浓度推算中国国标 AQI。

香港各站时间独立检查，过期/缺失站点剔除；中环、铜锣湾、旺角路边站不参与一般站最高值。无有效一般站时显示不可用。Android通过固定白名单地址请求香港官方JSON；本地预览采用同一路由，不接受任意代理地址。

## 调研及原始文档

- [Open-Meteo 空气质量](https://open-meteo.com/en/docs/air-quality-api)：CAMS欧洲/全球模型，全球网格约45公里；保留CAMS、Copernicus和Open-Meteo署名。
- [WAQI API](https://aqicn.org/api/)及[Token申请](https://aqicn.org/data-platform/token/)：监测站查询、原环保机构署名、使用条款；不得作为缓存/归档数据再分发。当前为个人使用接入；组织公开使用须按其条款另行处理。
- [OpenWeather Air Pollution API](https://openweathermap.org/api/air-pollution)：坐标查询、API Key、1–5级及浓度单位。
- [香港政府数据目录](https://data.gov.hk/en-data/dataset/hk-dpo-datagovhk2-city-dashboard-aqhi)链接的[各站JSON](https://dashboard.data.gov.hk/api/aqhi-individual?format=json)：逐小时更新，明确为香港AQHI。
- 另考察[和风天气](https://dev.qweather.com/en/docs/api/air-quality/)、[认证要求](https://dev.qweather.com/en/docs/configuration/authentication/)及[IQAir](https://www.iqair.com/support/knowledge-base/access-airvisuals-aqi-air-quality-and-pollution-api)：均需要账户凭据。此版优先接入以上四源，未把未实现的来源放进选项。
