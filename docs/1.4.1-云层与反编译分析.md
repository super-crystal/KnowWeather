# 1.4.1：云层、场景和反编译分析

2026-10-25。用户明确要求参考ColorOS APK的素材和参数改进动态背景、打包发送，并否定了初版程序生成的圆球状云。另提供多云、阴天、小雨三张参考截图；本版以自然云缘、厚薄、清晰蓝天/灰天及上方主视觉布局为目标。

## 已实际反编译的入口

官方JADX1.5.6（https://github.com/skylot/jadx/releases/tag/v1.5.6），命令行在本地读取用户APK，没有上传APK到第三方反编译网站。配置和缓存均在工作区tools/jadx；输出位于项目根相对 ../weatherly-reference/ColorOS/decompiled/。

- CoeAnimInfo：将天气动画类型及过渡标记组成Event参数；同一动画类型/城市避免重复派发。
- WeatherCoeEngine：创建COEEngine，实际读取assets/weather.coz2，解包缓存后调用loadCOE2；使用EventCenter发送天气、透明度、前后台和长按事件；按Surface持有者启动/暂停引擎，首帧事件用于完成初始化。
- DefaultWeatherEffectController：天气/时段更新委托引擎，页面onStart/onPause联动；垂直滚动通知背景透明度变化。

JADX退出码3、报告2项错误；保存的是恢复出的Java视图，部分复杂协程方法不能视为可直接编译的完整源码。关键加载、事件与生命周期调用可读，且weather.coz2的JSON/Lua/GLSL可以直接读取交叉核对。没有声称完整逆向native VFX引擎。

## 云层的实际组织

cloudy-noon Prefab包含c05、b04、b09、b03等云族，分组布局和多份循环副本。CloudMoveControl按各组速度和随机间距连续移动，越界回收到队尾；速度系数平滑逼近目标。CloudPropertyControl处理云的透明度、阴影、高光、渐变、gamma和天气切换插值。

对应云材质使用u_NormalTex。Shader将RGB由0…1映射为-1…1法线、归一化，与方向光/点光计算，再加渐变、对比度、gamma和色调映射；原图Alpha保存云缘。蓝紫色原图是数据纹理，不能作为普通彩云贴图。参考截图中云的细碎轮廓和内部明暗来自这些数据与着色过程。

## 本版实际适配

- 撤掉被用户否定的球状程序云。research/cloud-inputs保留用户APK中b04、b09、b03、c05的解码法线输入，research/shade-clouds.py进行法线方向光着色、垂直UV方向校正、透明边缘处理，输出4张云层WebP。research/cloud-assets.json记录原APK哈希、输入和输出哈希，明确是用户提供素材的派生图，不冒称独立原创纹理。
- 手机运行时异步读图并缓存白天、暮光、阴雨、夜间色调；每帧仅移动已缓存的图层。加载失败仍用原Canvas云回退，不显示破图。没有打包原APK、COE原生库、Lua或反编译Java。
- 云层按前后景分别移动，使用累计位移与平滑风速，避免刷新天气时突然跳位；循环回收在屏幕外。保留原始宽高比，避免积云被压成扁条。
- 依参考图将主云集中在天气顶部，向信息卡片上方自然消散；多云保留蓝天间隙，阴/雨使用灰蓝色调；雨线与云层深浅分别控制。
- 使用天气数据当地时间区分朝霞/夕照，is_day优先控制实际昼夜；夜雨/夜雪不画太阳。天气变化时颜色及云层过渡，减少动态效果、后台、弹窗和滚动时沿用暂停策略。

这是一套适配现有Android WebView/Canvas的渲染，不是完整移植厂商VFX引擎。验证、正式APK哈希与交付状态见output/qa-1.4.1/及工作记录；不得将模拟器绘制提交时间称为实体手机FPS。
