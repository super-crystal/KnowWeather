# 知天气 Android 1.4.1

支持十五日预报、随天气变化的背景、城市管理和天气详情。包名 cn.weatherly.app，版本代码 11，最低 Android 6.0（API 23），编译与目标 Android 16（API 36）。沿用原签名，可覆盖升级旧版。

后续续作优先阅读 [项目状态](docs/PROJECT_STATUS.md) 和 [Git版本管理](docs/Git版本管理.md)；本机工作记录保留在本地，不上传。阶段完成或中断前更新状态。1.3.0 参考 FlClash 的容器裁剪、短距离分类切换、运动期间合并刷新和快照主题淡变，独立适配 WebView 与 Android；分析及固定源码链接见 [FlClash动画分析](docs/FlClash动画分析.md)。

版本通过 Git 提交和 `v1.0.0`～`v1.4.1` 标签管理，逐版说明与APK哈希见 [发布记录](docs/releases/manifest.json)。原版本文件夹保留为本地历史备份；后续源码只维护这一份工作区，安装包通过GitHub Releases或既有网盘发布。私有源码仓库：[super-crystal/KnowWeather](https://github.com/super-crystal/KnowWeather)。

右上角“城市”支持搜索、添加、切换、上移排序和移除，最多保存 20 个城市。“天气详情”提供实况、48 小时、15 日、空气质量、气象信息、日出日落、生活建议、降水雷达、台风路径、双城对比和天气预警。不含广告或内容推荐。晴、多云、阴、雾、雨、雪、雷暴及晴朗/多云夜晚分别展示对应背景，应用界面统一浅色，不随系统进入深色模式；实际夜间天气背景仍保留。

## 数据与覆盖

- 地区模型经 Open-Meteo 获取；中国可选中国气象局 CMA / ECMWF / 自动。当前天气是模型估算，非气象站实测。
- 区域模型不足十五日时，使用 Open-Meteo Best Match 按日期补齐，逐日标明实际来源；缺失指标保持空缺，不生成虚构数据。远期预报可能有较大变化。
- 空气质量来自 CAMS 模型，采用美国 AQI 标准。
- 降水地图使用 OpenStreetMap 和 RainViewer，提供过去约两小时的雷达回波与覆盖遮罩。无覆盖地区不能据空白地图判定没有降雨。
- 台风来自中央气象台公开数据，展示实测路径、BABJ 预报路径、最近观测和中心气象信息。
- 中国大陆预警来自中国天气网；按城市所在省份及附近 50 km 匹配，可查看全部发布地区。香港使用香港天文台，美国使用 NOAA；其他地区尚未接通预警时明确提示。未匹配到资料不能保证没有预警。
- 生活建议为应用按天气计算，非官方生活指数。来源、获取时间、缓存状态和缺失情况均在页面说明。

APK 内置界面，可离线打开并使用最近缓存；获取天气和地图需要联网。请求过期响应不会覆盖新城市。主页定位在点击“使用当前位置”时开启；桌面卡片有独立定位流程，后台更新需位置的“始终允许”权限，坐标用于解析区域与查询当地天气。

## 桌面卡片

保留实时天气及日出日落两种 2×2 可缩放小组件。页面底部“卡片中心”提供添加、预览、刷新与随天气/浅色两种外观。卡片独立定位，不受应用内手动选城影响；同步数据源偏好和温度单位，约每 30 分钟后台更新，受系统节电调度影响。厂商专有卡片中心是否收录由桌面系统决定。

## 构建

需要 Java 21、Android SDK Platform 36、Build Tools 35.0.0 和 Node.js。执行 ./build.ps1 -SdkRoot /path/to/android-sdk -JavaHome /path/to/jdk-21；测试执行 node --test --test-isolation=none motion.test.mjs location.test.mjs map-health.test.mjs weather-data.test.mjs sky.test.mjs。

prepare-assets.mjs 从 web-src/ 打包离线界面，并生成原有城市目录。Leaflet 1.9.4 随包附带，无需运行时从 CDN 加载。构建脚本使用官方 AAPT2、D8、zipalign、apksigner，校验资产路径与签名。原有已发布网页保持原版本。

原生层仅提供本地安全域的受限天气快照同步，以及固定气象机构的公开数据请求；不提供通用网络代理或任意代码执行接口。外部主页面链接由系统浏览器打开。

构建产物位于 output/builds/。可加 -Unsigned 做无密钥验证；正式签名使用本机 .signing/ 或显式 -KeyStore/-PasswordFile。缺失原密钥时不会自动生成新身份。签名密钥必须单独保留才能持续覆盖升级，不进入Git或Releases。安装包不包含私钥。Android 16 验证截图和记录位于 output/qa-1.4.1/。
